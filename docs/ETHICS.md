# Ethics and Responsible Use

Housing models can affect people financially and socially. Treat this project as a decision-support prototype, not an automated decision maker.

## Required Safeguards for Real Use

- Verify data provenance and consent.
- Check for bias across protected or proxy groups.
- Monitor performance drift over time and geography.
- Explain prediction uncertainty to users.
- Keep a human review path for high-impact decisions.
- Avoid using the model for lending, insurance, taxation, or legal decisions without domain expert review.
